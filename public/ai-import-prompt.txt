첨부한 학교 시간표 이미지를 읽고 아래 JSON 형식으로 변환해 주세요.

반드시 지킬 규칙:
1. 설명, 마크다운 코드 블록, 주석 없이 유효한 JSON 객체만 출력하세요.
2. 월요일=1, 화요일=2, 수요일=3, 목요일=4, 금요일=5로 표현하고 주말 수업은 제외하세요.
3. 시간은 24시간제 HH:MM 형식으로 작성하세요.
4. 격주 시간표라면 cycle은 "biweekly"로 하고 각 수업의 week를 "A", "B", 또는 매주인 "ALL"로 지정하세요.
5. 매주 동일하면 cycle은 "weekly"로 하고 모든 수업의 week를 "ALL"로 지정하세요.
6. anchorDate에는 A주가 시작되는 월요일 날짜를 YYYY-MM-DD로 넣으세요. 알 수 없다면 오늘이 포함된 주의 월요일을 넣으세요.
7. 교실을 알 수 없으면 room은 빈 문자열로 두고 과목을 임의로 추가하지 마세요.
8. id는 생략해도 됩니다. reminderMinutes는 5, 10, 15, 30 중 하나이며 기본값은 10입니다.

출력 스키마:
{
  "format": "next-class-timetable",
  "version": 1,
  "cycle": "weekly 또는 biweekly",
  "anchorDate": "YYYY-MM-DD",
  "reminderMinutes": 10,
  "classes": [
    {
      "day": 1,
      "week": "A 또는 B 또는 ALL",
      "name": "과목명",
      "room": "강의실",
      "start": "09:00",
      "end": "09:50"
    }
  ]
}

종료 시간을 알 수 없으면 다음 교시 시작 직전 또는 이미지의 교시 시간표를 기준으로 합리적으로 추정하되, 추정 설명 없이 JSON에만 반영하세요.
