첨부한 학교 시간표 사진을 분석하여 Next Class 앱에서 가져올 수 있는 JSON 파일을 만들어 주세요.

중요: 바로 변환하지 말고, 파일 생성에 필요한 정보가 사진이나 대화에 명확히 없는지 먼저 확인하세요. 다음 항목 중 하나라도 불명확하면 임의로 추측하지 말고 사용자에게 구체적으로 질문한 뒤 답변을 기다리세요.

- 매주 같은 시간표인지, A/B 격주 시간표인지
- 격주라면 어떤 수업이 A주/B주/매주인지
- 격주라면 A주가 시작되는 월요일 날짜(YYYY-MM-DD)
- 사진에 교시 번호만 있다면 각 교시의 정확한 시작·종료 시각
- 과목명, 요일, 강의실 또는 수업 시간이 흐리거나 여러 방식으로 해석되는 부분
- 알림 시점(수업 5분, 10분, 15분, 30분 전 중 하나)

질문은 한 번에 빠짐없이, 사용자가 이해하기 쉬운 번호 목록으로 작성하세요. 필요한 정보가 모두 확인된 뒤에만 파일을 생성하세요.

파일 생성 규칙:
1. 답변 본문에 JSON 텍스트나 마크다운 코드블록만 표시하지 마세요.
2. 유효한 JSON 내용을 담은 실제 다운로드 가능한 파일을 생성하여 첨부하세요.
3. 파일명은 next-class-timetable.json으로 지정하세요.
4. 설명이 필요하면 파일을 첨부한 뒤 한두 문장으로만 안내하세요.
5. 월요일=1, 화요일=2, 수요일=3, 목요일=4, 금요일=5로 표시하고 주말 수업은 제외하세요.
6. 시간은 24시간제 HH:MM 형식으로 작성하세요.
7. 매주 동일하면 cycle은 "weekly", 모든 수업의 week는 "ALL"로 지정하세요.
8. 격주이면 cycle은 "biweekly", 각 수업의 week는 "A", "B", "ALL" 중 하나로 지정하세요.
9. anchorDate는 A주가 시작되는 월요일 날짜를 YYYY-MM-DD로 작성하세요. weekly인 경우에도 사용자가 제공한 기준일 또는 현재 주의 월요일을 사용하세요.
10. 강의실을 알 수 없으면 room은 빈 문자열로 두세요. 과목이나 시간을 임의로 만들지 마세요.
11. 각 수업의 id는 생략해도 됩니다.
12. reminderMinutes는 5, 10, 15, 30 중 사용자가 선택한 값으로 작성하며, 사용자가 선택하지 않았다면 반드시 먼저 질문하세요.

파일 내부 JSON 스키마:
{
  "format": "next-class-timetable",
  "version": 1,
  "cycle": "weekly 또는 biweekly",
  "anchorDate": "YYYY-MM-DD",
  "reminderMinutes": 10,
  "classes": [
    {
      "day": 1,
      "week": "A 또는 B 또는 ALL",
      "name": "과목명",
      "room": "강의실",
      "start": "09:00",
      "end": "09:50"
    }
  ]
}

마지막으로 파일을 만들기 전에 모든 수업의 종료 시각이 시작 시각보다 늦는지, 필수 필드가 빠지지 않았는지, JSON 문법이 유효한지 검증하세요.
